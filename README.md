# ProjetosC

Repositório dedicado aos meus estudos e exercícios desenvolvidos em **linguagem C**.

O objetivo é registrar a evolução prática em lógica de programação, vetores, matrizes, strings, ponteiros e outros fundamentos da linguagem.

## 📚 Conteúdos
- Lógica de programação
- Estruturas condicionais e de repetição
- Vetores e matrizes
- Strings
- Funções
- Ponteiros
- Entrada e saída de dados
- Geração de valores aleatórios
- Organização de código em funções utilitárias

## 📁 Organização
- `ListaMatrizes1/` — exercícios de matrizes.
- `ListaMatrizes2/` — exercícios complementares de matrizes.
- `ListaStrings/` — exercícios de manipulação de strings.
- `utils.c` — funções utilitárias reutilizáveis e exemplos de conceitos estudados.

## ▶️ Compilação e execução
Com GCC:

    gcc arquivo.c -o programa
    ./programa

Para programas que utilizam `utils.c`, compile os arquivos juntos:

    gcc programa.c utils.c -o programa
    ./programa

## 🚧 Status
**Em desenvolvimento contínuo.**

Este é principalmente um repositório de estudos, portanto alguns exercícios priorizam a prática de conceitos específicos em vez de uma arquitetura de produção.

## 🎯 Objetivo
Construir uma base sólida em C e utilizar os exercícios como evidência prática da evolução em programação, algoritmos e estruturas de dados.
