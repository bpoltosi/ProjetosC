# Trabalho para a disciplina de Linguagem de Programação.
Elaborar um script para jogar bingo automaticamente (usuario só valida "space" para a continuacao para proxima rodada).
tabela com 15 numeros (5x3) diferentes, nao sequenciais, entre 1 e 60.
jogadores com o mesmo nome recebem codinomes.
tabelas sao exibidas a cada rodada.
array de numeros ja sorteados tambem sao exibidos toda rodada.
o jogador que tiver sua tabela preenchida primeiro, grita "Bingo!" e ganha o jogo.
PLUS -> contador de vitorias.
